# 轻工大移植说明

本仓库由 [ZZUPocket](https://github.com/3beuml/ZZUPocket)（郑州大学校园助手，MIT）改造而来，
目标学校为**郑州轻工业大学**，App 名称为「泥轻助手」。

当前版本：`0.1.1`（versionCode 90）

## 1. 使用的学校系统

| 能力 | 系统 / 地址 | 说明 |
|---|---|---|
| 统一身份认证 | `https://kys.zzuli.edu.cn`（KYS CAS） | 支持短信登录、i轻大扫码 |
| 教务 | `https://jwgl.zzuli.edu.cn`（青果 KINGOSOFT） | 课表、成绩、考试、学籍、空闲教室 |
| 天气 | Open-Meteo（按定位经纬度） | 免费、无需 key |
| 节假日 | timor.tech | 免费接口，失败时固定节日兜底 |

## 2. 已实现功能

- **登录**
  - 短信登录（主）：内置 WebView 打开学校统一认证，登录后自动抓取学号；
  - 扫码登录（备）：本地生成 `cas/openAuth?uuid=...` 二维码，轮询授权状态；
  - 登录会话加密持久化，退出登录清除。
- **课表**
  - 青果课表页解析，支持单双周、周次范围；
  - 本地 Room 缓存，**断网/未登录也能看**；
  - 开学日期（第 1 周周一）可手动设置，App 自动算当前周；
  - 首页「今天」竖排显示：最近刚上完的一节 → 正在上 → 未开始；刚上完的课缩小变浅。
- **成绩**
  - 按学期分组、同学期合并；
  - 正序/倒序切换，切换后回到顶部；
  - 平时/期中/期末/综合成绩。
- **考试**：原生列表；无排考时提供学校网页兜底。
- **学籍**
  - 学号、姓名、性别、身份证号、考生号、入学时间、专业、学制、层次、院系、班级、生源单位；
  - 身份证号/考生号默认脱敏，可单独显示、复制；
  - 本地加密缓存，下次进入先显示缓存再刷新。
- **空闲教室**
  - 校区：东风 / 科学 / 禹州；
  - 教室类型：默认「多媒体」，可切语音室/智慧教室/计算机房；
  - 周次、星期、起止节次筛选。
- **首页**
  - 今日课程、日期+天气概览、快捷入口（空闲教室/学籍）；
  - 日历：默认近三周（本周居中），可展开整月；
  - 展开后左右箭头/拖动切换月份；节假日红色「休」、调休「班」。
- **桌面小组件**：今日课程、今明课表、下一节课。

## 3. 待开发 / 已知限制

1. **电费 / 校园卡**：入口显示「待开发」。
   学校电费在 i轻工大「完美校园云缴费」H5 里，登录用一次性 `pay.do?username=...&code=...`，
   `code` 由服务端生成、用过即失效，外部无法自动登录，故暂不实现。
2. **研究生系统**：界面已隐藏（登录状态页不再显示研究生教务卡片，课表页不再显示研究生入口）。
3. **扫码登录自动学号**：扫码会话建立后，部分账号仍可能识别不到学号而要求补填一次；
   短信登录的自动识别是稳定的。
4. **天气**：无定位权限/无定位数据时退回郑州；只显示当前与今日高低温。
5. **空闲教室**：暂未提供「楼房」筛选（接口参数 `sel_lf` 已确认，可后续补）。
6. **节假日**：接口只覆盖已公布年份，跨年时可能只有固定节日。

## 4. 构建

环境：JDK 17 + Android SDK 36 + Gradle 8.9。

```powershell
$env:JAVA_HOME="...\tools\jdk17"
$env:ANDROID_HOME="...\tools\android-sdk"
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:assembleRelease
```

- Debug 包：`app/build/outputs/apk/debug/app-debug.apk`
- Release 包：`app/build/outputs/apk/release/app-release.apk`

Release 签名读取仓库根目录的 `keystore.properties`（已 gitignore），字段：
`storeFile / storePassword / keyAlias / keyPassword`。

## 5. 数据与隐私

- 不保存密码，只保存学校下发的会话（加密存储）；
- 课表、成绩、学籍等只存本机数据库，无自建服务器；
- 学籍敏感字段默认脱敏；
- 仓库与文档中不提交个人成绩、身份证号、Cookie、学号截图。
